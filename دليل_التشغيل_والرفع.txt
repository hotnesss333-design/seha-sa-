====================================================================
دليل تشغيل منصة صحة (قاعدة بيانات مستقلة 100% محمية)
====================================================================

البنية الحالية:
--------------------------------------------------------------------
- الموقع منصة ثابتة على Netlify، وواجهات API تعمل عبر Netlify Functions
  (netlify/functions/) بالمسارات المعرّفة في netlify.toml.
- قاعدة البيانات: Postgres مُدارة مستقلة خاصة بالموقع (Netlify Database)
  مع Drizzle ORM. التعريفات في db/schema.ts والتحديثات في
  netlify/database/migrations/ وتُطبَّق تلقائياً عند النشر.
- لا يوجد أي اتصال بأي خدمة خارجية: كل البيانات (الإجازات، مرافقي
  المرضى، حسابات الإدارة) تُحفظ في قاعدة بيانات الموقع المستقلة فقط،
  وطبقة الحماية داخل الموقع تحجب أي طلب موجّه لخدمة خارجية.

بيانات لوحة الإدارة:
--------------------------------------------------------------------
- تم تحديث بيانات دخول الإدارة بالكامل كما طُلب (لا تُكتب في الملفات
  ولا في الكود). كلمة المرور مخزنة مشفّرة في قاعدة البيانات فقط.
- يمكن تغيير رقم الهوية وكلمة المرور في أي وقت من لوحة التحكم عبر
  زر «إدارة الحسابات وكلمة المرور»، وستُلغى كل الجلسات القديمة تلقائياً.
- حماية الدخول: تحقق كامل من الخادم، جلسات آمنة HttpOnly، تحديد معدل
  المحاولات الفاشلة، ورسائل خطأ موحدة.

التشغيل محلياً:
--------------------------------------------------------------------
1) npm install
2) npm run dev  (تشغيل Netlify Dev مع محاكاة الدوال وقاعدة البيانات)
   أو: npm start (خادم ثابت فقط للمعاينة دون API)

النشر:
--------------------------------------------------------------------
- npm run build يجهّز مجلد dist/ للنشر.
- ملف الأمان SECURITY.md يوثّق كل إجراءات الحماية المطبقة.
- ملف التحقق googledbcfb73b6979be60.html لملكية الموقع في Google
  Search Console موجود ويُنشر تلقائياً.
