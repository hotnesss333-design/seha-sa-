# منصة صحة - بوابة الخدمات الصحية الإلكترونية (Seha Platform)

تمت إعادة كتابة وتطوير المشروع بالكامل كتطبيق **React** حديث باستخدام **TypeScript** و**Vite** و**Tailwind CSS**، مع الحفاظ الكامل على كافة الميزات والمنطق البرمجي والهوية البصرية لمنظومة وزارة الصحة بالمملكة العربية السعودية.

## الميزات الرئيسية

- **الاستعلام عن الإجازات المرضية ومرافق المريض**:
  - استعلام فوري مباشر برمز الخدمة (Service Code) ورقم الهوية الوطنية أو الإقامة.
  - دعم تقارير الإجازات المرضية (Sick Leaves) وتقارير مرافقي المرضى المنومين (Patient Companions) مع تحديد صلة القرابة والمدة.
  - عرض شهادة التقرير الرسمية المعتمدة والمزودة برمز التحقق وشعار وزارة الصحة وخاتم التوثيق الرقمي.
  - إمكانية الطباعة المباشرة (`window.print()`) ونسخ الرمز.
  - دعم الاستعلام السريع عبر معلمات الرابط (`?id=...&code=...`).

- **لوحة تحكم إدارة التقارير والمستخدمين (Dashboard)**:
  - إدارة شاملة للإجازات المرضية ومرافقي المرضى.
  - إصدار وتوليد رموز خدمة جديدة (GSL / CMP).
  - إضافة وتعديل وحذف التقارير مع حفظ فوري ومزامنة للبيانات.
  - إدارة مستخدمي ومسؤولي النظام.
  - مؤشرات وإحصائيات حية لعدد التقارير، السارية، والمنتهية.

- **دليل الخدمات الصحية**:
  - تصنيف الخدمات للأفراد، المنشآت والشركات، والممارسين الصحيين.
  - البحث والتصفية حسب الكلمات المفتاحية والفئات.

- **منصة صحة بلس (Seha Plus)**:
  - استعراض مزايا وحلول الأعمال والمنشآت.
  - جدول مقارنة تفصيلي للباقات وخدمات الربط الآلي (API).

- **تسجيل الدخول والنفاذ الوطني**:
  - دعم تسجيل الدخول باسم المستخدم وكلمة المرور.
  - محاكاة مصادقة النفاذ الوطني الموحد (نفاذ - IAM).

## التقنيات المستخدمة

- **React 19** & **TypeScript**
- **Vite** للبناء والتطوير السريع
- **Tailwind CSS v4** للتنسيق
- **Lucide React** للأيقونات
- حفظ واسترجاع دائم للبيانات مع دعم المزامنة والنسخ الاحتياطي السحابي

## التشغيل والتطوير

```bash
# تشغيل خادم التطوير (على المنفذ 3000)
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
